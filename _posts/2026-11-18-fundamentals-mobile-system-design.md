## Description 

Mobile apps aren’t thin clients anymore. They cache, sync, stream, retry, paginate and recover, all without dropping a frame. 
In this video I walk through the framework I use to design any mobile feature, from the first requirement to the rollout,
using a news feed as a real example.

⏱️ What we cover:
- The 4-question framework: scoping, API design, storage and architecture
- Networking: REST, pagination, auth, CDNs and push notifications
- Caching and offline-first design
- Architecture, error handling and optimistic writes
- Rollouts, performance and more topics such as accessibility, security and app size

Whether you’re building a feature, leading a mobile team, or preparing for a system design interview, this is for you.
